# Apéndice manuscrito
Pendiente de elaboración personal por David Julio Olano Silva Nevado para la entrega final.

La [guía completa](derivaciones-guia.md) desarrolla Bayes, las varianzas pública y oculta, la covarianza, las creencias, la utilidad CARA, las CPO, el precio y la sensibilidad. Deben reproducirse personalmente a mano; una guía tipografiada no reemplaza el apéndice manuscrito exigido por el curso.

Añadir fotografías o escaneos legibles, con las reglas y condiciones de cada paso. La extensión con sentimiento endógeno sigue abierta y no se presenta como resultado demostrado.
